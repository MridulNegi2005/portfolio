# Case study screenshots

Put three PNG files here. The site loads each one lazily, inside the project panel.
The panel is closed by default, so the images do not add page length until a visitor
opens a project.

| File | Suggested content |
|---|---|
| `mahoraga.png` | The React dashboard, mid-episode |
| `plantbrain.png` | A cited answer, showing sources and confidence |
| `cosmic-bot.png` | A Pillow-rendered rank card in a live channel |

Rules:
1. Use a 16:9 or 16:10 crop. The site crops to 390 px tall from the top.
2. Keep each file under 300 KB. Resize to 1200 px wide before saving.
3. Remove private data: real names, user IDs, tokens, internal URLs.

A missing file removes its own slot, so the site stays correct until you add them.
